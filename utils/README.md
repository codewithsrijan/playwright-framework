# Utilities

- **`utils/commonfuctions.ts`** — file I/O, JSON test data, random IDs, and other non-UI helpers (legacy filename preserved for imports).
- **`utils/playwright/`** — browser-specific helpers (`navigation`, screenshot attachments) that depend on `@playwright/test`.
- **`framework/wait/`** — centralized timeouts and wait helpers used by page objects and fixtures.
